# Pierre Moraes — Developer Portfolio

Portfolio pessoal minimalista inspirado na linguagem visual do Forge Project, adaptado para um perfil profissional de developer.

## Stack do site

- React
- Vite
- CSS responsivo
- GitHub Pages
- Português / English

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

O repositório inclui `.github/workflows/deploy.yml` para publicação automática no GitHub Pages a cada push na branch `main`.
